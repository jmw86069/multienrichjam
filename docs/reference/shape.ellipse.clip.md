# clip function for igraph vertex shape ellipse

clip function for igraph vertex shape ellipse

## Usage

``` r
shape.ellipse.clip(coords, el, params, end = c("both", "from", "to"))
```

## Details

This function defines the clipping function for custom igraph vertex
shape ellipse.
